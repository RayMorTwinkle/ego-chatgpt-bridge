## 仍有限制

- UI 型号与模型后端之间没有可验证的强绑定；两个调度任务状态重叠也不能证明后端推理真正并行。
- 当前适配依据繁体界面。未来 DOM、其他语言、长对话虚拟化和历史分页仍可能导致安全停止或部分导出。ZIP 明确标注已加载内容范围，不保证全量服务端历史。
- 音视频、交互预览的原始导出未逐类实测；未知内容显式列为未完成输出。
- 账户身份只核对网页显示名，不是稳定的账户 ID；用户对同一对话的外部修改不能全部可靠识别。
- 取消是尽力操作，不能撤回已发送输入；结果未知的操作不能强制重发。
- 第二台实体设备的 EasyTier 连通性／防火墙仍需在那台设备验证。本次独立客户端是本机通过真实 EasyTier 地址访问，没有冒称跨设备验收。
