# 验证范围

真实网页测试与模拟故障分开记录。

## 已做的真实验证

- 固定專案创建、GPT-6 高／极高选择及刷新后核验。
- 异步创建、同会话追问、幂等复用、两个会话的调度状态重叠。
- 服务在提交后的等待阶段重启，恢复到完成，未出现重复用户消息。
- CSV、DOCX、PNG、PDF 从网页文件卡片取得字节，HTTP 回传大小和 SHA-256 一致；CSV 内容、DOCX XML、PNG 尺寸及 PDF 页对象进一步检查。
- 原生图像生成的纯图片回复取得有效 PNG；认证 HTTP、HEAD／Range、原生 MCP ImageContent 及 ResourceLink 回传字节一致。
- 匿名下载拒绝，跨身份下载不可见。
- WebUI 真实 HTTPS 登录、一年 cookie 属性、MCP 配置信息、公有证书下载、5 个既有产物下载及服务重启后登录保持。
- EasyTier 地址监听可达，回环和物理网卡同端口不可达；来源 CIDR 及伪造转发头另有隔离测试。

早期二进制捕获曾得到空内容，后来改用实际 UI 返回资源地址的浏览器下载语义，并处理旧文件卡片的视口定位。只在真实非空字节验证后标记 AVAILABLE。

## 自动化测试

测试包括幂等冲突、队列排序、跨身份隔离、发送边界中断、迟到结果、部分内容、取消、产物损坏、原子文件恢复、认证下载、MCP 协议、一年 cookie 与轮换、UI 同源保护，以及 WebUI-only 调试导出边界。使用 FakeBrowser 的故障注入不等于网页检测器已识别过每一种真实故障。

运行：`~/apps/ego-chatgpt-bridge/.venv/bin/python -m pytest -q`。

## 未保证的能力

- 不能证明 UI 显示型号就是实际后端模型，也不能证明两次推理在后端真正同时执行。
- 浏览器／系统重启后的空间持久化和自动冷启动未完整验证，空间丢失会明确停止。
- 当前 DOM 适配基于繁体界面，其他语言、未来 DOM、长对话虚拟化／历史分页可能导致安全停止或部分导出。
- 一次冷页面新建任务因找不到模型选择器而在发送前安全停止；已有对话追问及产物回传已验证，该冷页面场景仍待继续核验。
- 音视频和交互预览的原始导出未逐类实测；未知内容不会伪装成完整文件。
- 取消网页生成是尽力操作，不能撤回已发送输入。
- 第二台实体设备的 EasyTier 防火墙／连通性尚未代替用户测试。

WebUI 浏览器视觉检查及真实对话 ZIP 导出待完成；相应接口已通过隔离模拟测试。
